## 使用规则

- 中国大陆联系人使用简体中文；海外联系人使用英文。
- 每封邮件必须说明为什么联系对方，避免群发感。
- PoL2 是项目背景，不要求对方先认同 PoL2 才能回答问题。
- 第一封邮件只保留一个核心 CTA。
- 对方回复后，再发送 1–2 页 research brief、完整 PDF、实验设计或代码入口。
- 同一机构第一轮不同时联系多人。
- 正式发送当天重新核验职位、邮箱、机构与近期研究方向。
