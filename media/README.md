# media

NaturalDAO 对外宣传物料 / Promotional materials for NaturalDAO.

| 目录 | 用途 |
|------|------|
| `video/`     | 宣传视频、演示录屏 |
| `images/`    | Logo、海报、截图、配图 |
| `copy/`      | 文案、slogan、项目介绍稿 |
| `press-kit/` | 整理好可直接提供给媒体 / 合作方的一套物料 |

大于几十 MB 的视频请勿直接提交进 git，建议放到 Release 附件或外部存储，此处只保留缩略图与链接。
