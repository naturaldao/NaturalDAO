# media

NaturalDAO 对外宣传物料 / Promotional materials for NaturalDAO.

| 目录 / Directory | 用途 / Purpose |
|------|------|
| `video/` | 宣传视频、演示录屏 / Promotional videos and demo recordings |
| `images/` | Logo、海报、截图、配图 / Logos, posters, screenshots, and illustrations |
| `copy/` | 文案、slogan、项目介绍稿 / Copy, slogans, and project descriptions |
| `press-kit/` | 整理好可直接提供给媒体或合作方的一套物料 / Curated materials ready to share with media or partners |
| `表情包Sticker/` | 表情包、贴纸与反应图 / Stickers, emoji, and reaction images |
| `歌曲Song/` | 歌曲、配乐与音频 / Songs, music, and audio |

大于几十 MB 的视频请勿直接提交进 git，建议放到 Release 附件或外部存储，此处只保留缩略图与链接。

Please do not commit videos larger than a few dozen MB directly to Git. Use a Release attachment or external storage, and keep only thumbnails and links here.
