# 通用决策数据集 general（v0.1）

给**只做"选一个"的小决策模型**用的中英双语数据集：**71,356 条**，每条都是
「情境 → 一个或多个类型化问题 → 候选项或量程 → 答案」的完整四元组，答案可以带概率分布。

它不是某个垂直领域的语料。本页用一次**能力维度审计**说明它训练的是什么能力、各占多少（§2），
再用**领域覆盖**说明它涉及哪些知识（§3），最后给出语言、来源、问题形态、真值四方面的覆盖数字（§4）。
页内每一个数字都能用一条命令复算（§6）。

> **定位与适用边界**：本数据集由公开可获取的选择式任务构成，以工具使用、行动选择、权限与风险判断
> 为主，并包含部分知识推理及人类判断任务。设计用途是在专项微调中提供辅助回放信号。
> 本数据集不代表通用大模型的预训练分布，也不保证覆盖全部通用能力；其防遗忘效果须通过具体模型、
> 训练配置及独立评测验证。

|---|---|
| 条目 / 问题 | **71,356 条 / 77,597 道问题**（100% 自带答案） |

## 1. 这是什么

### 1.1 目标模型只做"选一个"

它要能在一份**封闭候选集**里快速选出一项，而不是像大模型那样逐字生成。所以数据尽量保持
原生的 **（情境, 问题, 候选/量程, 答案）** 四元组：情境、问题、可选动作、答案都现成，
训练时不需要再"编题"。

形态统一**不等于**能力覆盖足够——同一句"选一个"，背后可能是多步计算、可能是检索整合、
也可能只是识别。上一轮审计曾显示：**工具与行动选择一维占了六成**，用于"选一个"的信号有了，
但能力面偏在一侧。

本轮因此补入两批**通用能力来源**（数学与形式逻辑、阅读理解与证据整合），公开三区条目增至
71,356。并源前后的对比见 §2.5：**它改变了偏斜的方向，没有消除偏斜**。

### 1.2 一条记录长什么样

下面四条取自公开分区，id 可直接在分区文件里查到：

### 1.3 三种问题原语，只有三种

| 原语 | 含义 | 答案形态 | 例 |
|---|---|---|---|
| **choice** | 多选一，选项 2–69 个 | 选项键，可带概率分布 | 选哪个接口 / 哪一类工单 / 哪条推理成立 |
| **noul** | 是 / 否（选项键可能是 yes/no 或 true/false） | 选项键，可带概率分布 | 这条告警要不要升级 |
| **score** | 整数分级，各题量程不同（实测 2–11 档） | 档位下标，可带概率分布 | 严重度打分 |

三种之外不发明第四种。有的题来源直接给了**概率分布**（如 `{"false": 0.87, "true": 0.13}`），
有的只给了硬标签——后者不会被伪造成分布，用法见 §4.4。

## 2. 能力维度审计（主口径）

### 2.1 口径

**问的问题不是"这条数据来自哪个任务"，而是"答对它必须会什么"。**

单位是条目，每条按固定优先级的规则链归入**恰好一个**能力维度，因此六类互斥、占比合计 100%。
一道题常常同时需要多种能力，本审计取**瓶颈能力**——缺了它就一定答不对的那一种。约定：

1. 有候选动作/接口菜单、要选"下一步做什么" → **工具与行动选择**；
2. 需要对数值、表格、时序、规则做形式化推演 → **数学与形式逻辑**；
3. 需要从多段材料里定位、比对、整合出证据 → **阅读理解与证据整合**；
4. 需要领域知识（医学/生化/工程/人文）才能判断 → **世界知识及其应用**；
5. 判定对象是"证据够不够、会不会发生、有无歧义" → **因果、反事实与不确定性判断**；
6. 判定对象是人的意图、情感、规范与多视角 → **社会与人类判断**。

判定依据是**来源自带的细分标签**（原生领域标签 / 任务键 / 文档类型 / 覆盖域 / 新并入来源的 config）
经固定映射表归并，映射表逐条写死在 [readme_stats.py](readme_stats.py) 里，不存在隐式规则；
规则命中数全部打印：

| 规则 | 依据 | 命中条目 |
|---|---|---:|
| C1 | 整份来源的形态就是"从候选菜单选动作" | 11,043 |
| C2 | 来源自带的细分领域标签（65 个取值） | 6,130 |
| C3 | 来源自带的任务键（task:arithmetic、task:table_lookup …） | 1,186 |
| C4 | 来源自带的任务键前缀（alloc. / debate. / ticket.） | 1,169 |
| C5 | 来源自带的原生域标签（客服控制流 / 游戏环境） | 626 |
| C6 | 来源自带的文档类型标签（28 种） | 347 |
| C7 | 中文补充集的覆盖域（risk_harm / human_judgment） | 3,148 |
| C9 | 数学/逻辑类新来源的 **config 级判读**（32 个 config 逐项映射，不是一律归数学） | 24,120 |
| C10 | 阅读类新来源的语境常识阅读理解 | 23,587 |
| — | 未命中任何规则 | **0** |

C9 有 **2 个 config 是刻意偏离接入时标签的**：`known_unknowns`（不可判定）与
`evaluating_information_essentiality`（数据充分性/概率比较）判为**因果、反事实与不确定性判断**
——题目本身就是"证据够不够、能不能判定"，不是数值推演。脚本会把这两处差异打印出来
（与数据里 `meta.capability` 的一致率 47,629 / 47,707 ＝ 99.84%，差异恰为这 78 条）。

抽样复核（每维 3 条、共 18 条真实条目，人眼过一遍）：

    uv run --no-project --offline python datasets/general/readme_stats.py --samples 3

复核结果：16 条归属无争议；2 条属边界情形——`temporal_reasoning` 的"期限压力打分"既是时间推算
也是不确定性评估，`research_data_mgmt` 的"数据集能否共享"既是合规规范也是研究判断。
"瓶颈能力"这一约定在**打分类**题上存在主观空间，这一点先说清楚。

### 2.3 每一维里装的是什么

**阅读理解与证据整合 · 30,667（42.98%）**——主体是**语境常识阅读理解**（23,587 条：
给一段日常叙事，判断叙述者的处境/意图/事件因果），加上新并入来源的语言与证据类任务
（5,417 条：指代消解、预设与蕴含、歧义消解、极性、隐性关系、寓言寓意、讽刺识别、事实核验），
以及旧来源的检索相关性/摘要/字段抽取（1,663 条）。

**数学与形式逻辑 · 20,227（28.35%）**——新并入来源的 18,625 条为主：多步算术与应用题、单位换算、
几何求交、最长公共子序列等算法题、日期推算、数学归纳、形式论证有效性、逻辑谬误识别、
约束满足（排序/网格）、棋类搜索（一步杀）、状态跟踪（洗牌后的持有物）、空间导航、时序推理；
另有旧来源的形式规则推演与结构化计算（925 + 600 条）。

**工具与行动选择 · 14,392（20.17%）**——中文侧是自然语言诉求 → 从一份候选接口菜单
（2–57 个，中位 4）里选正确的一个；英文侧是服务场景 + 候选动作菜单 → 选出下一步动作
（授权、转人工、退款、排期…）；其余 3,349 条是流程路由与处置判定：工单路由与优先级、
发布 go / no-go、值班故障定级、权限审批、该升级还是该拒绝、发票与库存处置。

**社会与人类判断 · 4,255（5.96%）**——中文侧的诈骗话术、有害内容与毒性识别（3,148 条）；
论辩裁决（谁赢、证据是否充分）与稀缺资源的公共分配；情感与意图、法律条款合规、科研数据伦理。

**世界知识及其应用 · 1,240（1.74%）**——医学生命（分诊、诊断推理、用药安全、临床文书、
遗传检测与变异解读）、生物信息与序列判读、化学与材料、仪器与仿真、生态与物种分类、
人文文本断代与教义归类。**这一维几乎全部来自旧来源（1,201 条来自同一来源族）**。

**因果、反事实与不确定性判断 · 575（0.81%）**——假设可否证性与证据强度、实验设计与统计功效、
同行评审、政策后果推演、安全告警归因，以及新并入来源里"不可判定/信息充分性"两个任务（78 条）。

### 2.5 换了一种偏斜，不是消除偏斜

把公开三区按**语料代际**拆开（行内占比 = 该代际内部的构成）：

| 语料代际 | 条目 | 占全部 | 工具 | 数学 | 阅读 | 世界 | 因果 | 社会 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 旧 11 个来源（v3 及以前） | 23,649 | 33.14% | 60.86% | 6.77% | 7.03% | 5.24% | 2.10% | 17.99% |
| 新并入 2 个来源 | 47,707 | 66.86% | 0.00% | 39.04% | 60.80% | 0.00% | 0.16% | 0.00% |
| **合并后（公开三区）** | **71,356** | **100%** | **20.17%** | **28.35%** | **42.98%** | **1.74%** | **0.81%** | **5.96%** |

读法：

1. **工具类垄断确实被打破了**：从旧子集内部的 60.86% 降到合并后的 20.17%。
2. **但偏斜被换成了另一侧**：新并入的 47,707 条里，除 0.16% 的因果外**全部是数学 + 阅读**
   （39.04% + 60.80%）；合并后这两维合计 **71.32%**。这不是"均衡"，是"从一个集中换成另一个集中"。
3. **世界知识与因果/不确定性被稀释得更薄**：旧子集内部还有 5.24% 与 2.10%，
   合并后降到 **1.74% 与 0.81%**——因为分母涨了近 3 倍，而这两维几乎没有新增供给。
4. 社会与人类判断同样从 17.99% 稀释到 5.96%。
5. **中文占比只有 15.44%**：两批新来源都是英文，分母变大后中文被稀释（§4.1）。

**下一轮的补强方向因此是明确的**：补**世界知识**与**因果/反事实/不确定性**类来源，
不再在两个新来源之间挪量——那只会把 71.32% 这个数字在数学与阅读之间来回搬。

### 2.6 审计结论与薄弱项

- **覆盖到 6 个能力维度**，但**仍然高度不均衡**：阅读 + 数学 = 71.32%，
  因果/反事实/不确定性只有 575 条（0.81%），世界知识只有 1,240 条（1.74%）。
- **世界知识一维只有 2 个来源，1,240 条里 1,201 条来自同一来源族**；阅读理解一维
  30,667 条里 23,587 条来自单一来源。这两维的域外泛化需要额外验证。
- **中文侧的领域跨度没有改善**：中文 11,020 条仍集中在工具（7,872）与安全（3,148）两处。
- **本审计是"用已有元数据做的审计"**：能力归属由来源自带标签经固定映射得到，
  不是独立人工标注，与来源自己的切分口径绑定；抽样复核只覆盖每维 3 条。
- **没有训模实验**：以上数字只能说明"数据集里有哪些能力的监督信号、各占多少"，
  **不能**说明"训练后模型的能力不会退化"。防遗忘效果须通过具体模型、训练配置及独立评测验证。

## 4. 其他覆盖面数字

### 4.1 语言

中英各自是**母语原生**的条目（来源原文 + 来源自带答案），不是互相翻译出来的。
本轮并入的两批来源都是**英文**，所以合并后中文占比为 15.44%：

| 分区 | 英文 | 中文 | 合计 |
|---|---:|---:|---:|
| train | 40,224 | 8,396 | 48,620 |
| test | 13,408 | 1,749 | 15,157 |
| validation | 6,704 | 875 | 7,579 |

中文集中在工具与安全两类，英文覆盖全部 11 个内容领域——中文侧的领域跨度是这份数据最明显的短板。

### 4.2 来源

**13 个独立来源**，最大的一家占 **33.80%**，第二家 33.06%，第三家 11.03%：
没有任何一家的表述习惯或标注口径能定义整个数据集；但前两家合计 66.86%，来源集中度偏高。

### 4.3 问题形态与规模

| 层面 | 分布 |
|---|---|
| 问题级（77,597 道） | choice 64,100（82.61%）· noul 7,881（10.16%）· score 5,616（7.24%） |
| 条目级（互不排斥） | 含 choice 63,447（88.92%）· 含 noul 6,909（9.68%）· 含 score 4,432（6.21%） |
| 每题挂载 | 1 题 69,285 条 · 2 题 132 · 3 题 950 · 4 题 296 · 5 题 144 · 6 题 549 |
| choice 选项数 | 最小 2、最大 69、中位 4 |
| score 档位数 | 2–11 档（3 档 2,100 道、5 档 1,732、6 档 1,410、10 档 303） |

选项规模与量程**不统一**是刻意的：把来源的 6 档压成 5 档等于改写题目
（口径见 [CONTRACT.md](CONTRACT.md)）。choice 占比升到 82.61% 是本轮并源的结果：
两批新来源都是原生多选形态。三种原语在各个能力维度上的分布见复算脚本第 2 节。

### 4.4 真值

77,597 道题**全部**带真值，但**分布形态很不均衡**：

| 真值形态 | 问题数 | 占比 | 旧 11 来源 | 新并入 2 来源 |
|---|---:|---:|---:|---:|
| 真概率分布（来源直接给出） | 5,905 | 7.61% | 5,905 | 0 |
| 硬标签转成的单点分布 | 11,140 | 14.36% | 11,140 | 0 |
| 均匀分布（无信息，多为低置信样本） | 1,389 | 1.79% | 1,389 | 0 |
| 只有硬标签、没有分布 | 59,163 | 76.24% | 11,456 | 47,707 |

**这是本轮并源付出的代价，必须写明**：新并入的两批来源（47,707 道题）**全部只有硬标签、
不带任何概率分布**——真分布、单点分布、均匀分布三项都是 0；7.61% 的真分布**全部来自旧 11 个来源**。
按旧来源内部计，真分布原本占其全部问题的 **19.76%**（5,905 / 29,890），并源后稀释到 **7.61%**。

我们没有把硬标签伪造成 one-hot 来"凑"分布（那会违背契约，也会教出退化解），代价是
**软目标监督的结构性下降**：现在 76.24% 的题只有 `answer`、没有 `probs`，
做 KL / 软交叉熵 / 校准这类分布类损失时可用信号只剩 7.61%。后续即使给一部分 noul 题补上
概率分布，补回的量级也远小于这 47,707 条——**"语料更通用了"和"软目标更多了"在本轮是相反的两件事**。

做分布类损失前必须按形态过滤（判据函数在 [CONTRACT.md](CONTRACT.md) §2.3）：把 14.36% 的
单点分布当概率用会学到退化解，均匀分布的 1.79% 等于在教模型"别确定"。

按**成色**分两层，训练时建议分开报告：

| 层级 | 条目 | 说明 |
|---|---:|---|
| 原生四元组 | 68,208 | 情境、候选项与答案都来自来源原文 |
| 单标签转换的补充 | 3,148 | 由"这条属于 X 类"的单标签转换而来（硬标签、无概率分布），按设计**只进 train** |

第二层在 test / validation 中为 0 条——它只影响 train 的构成，不会污染评测区。

## 5. 怎么用

### 5.1 文件与划分

| 文件 | 内容 | 用途 |
|---|---|---|
| [data/splits/train.jsonl](data/splits/train.jsonl)（[.gz](data/splits/train.jsonl.gz)） | 48,620 条 | 训练（含 3,148 条只进 train 的中文安全补充） |
| [data/splits/validation.jsonl](data/splits/validation.jsonl)（[.gz](data/splits/validation.jsonl.gz)） | 7,579 条 | 选模型、调超参 |
| [data/splits/test.jsonl](data/splits/test.jsonl)（[.gz](data/splits/test.jsonl.gz)） | 15,157 条 | 回归测试 |
| [data/splits/split-manifest.json](data/splits/split-manifest.json) | 哈希与聚合清单 | 校验下载完整性 |
| [split-report.md](split-report.md) | 切分报告 | 分区构成、泄漏检查 |

切分按**请求分组**进行：同一请求的多个变体（情境逐字相同、只是候选顺序不同）整组进同一分区。
三个分区两两之间的 id 重叠、组键重叠、归一化情境重叠**均为 0**（口径与复算见脚本第 6 节：
组键取 `meta.group_id` 或 `meta.request_id`，
归一化情境为去掉首尾与连续空白后转小写）。

语料总构成：公开三区 **71,356 条** + 内部保留集 **6,704 条**（不对外发布，用于上线前回归，
构成见 [split-report.md](split-report.md)）= **78,060 条**。

**三区的能力维度构成不均衡**，用 test / validation 做能力评估前请注意：

| 能力维度 | train | test | validation |
|---|---:|---:|---:|
| 阅读理解与证据整合 | 20,474 | 6,782 | 3,411 |
| 数学与形式逻辑 | 13,484 | 4,517 | 2,226 |
| 工具与行动选择 | 9,612 | 3,170 | 1,610 |
| 社会与人类判断 | 3,874 | 261 | 120 |
| 世界知识及其应用 | 807 | 291 | 142 |
| 因果、反事实与不确定性判断 | 369 | 136 | 70 |
| **合计** | **48,620** | **15,157** | **7,579** |

社会与人类判断一维在 test / validation 只有 261 / 120 条（中文补充集按设计只进 train），
**不要用 test / validation 评这一维**；需要时请从 train 的英文部分另切同构子集。

### 5.2 字段（详细契约见 [CONTRACT.md](CONTRACT.md)）

| 字段 | 说明 |
|---|---|
| `id` | 全局唯一，由（来源, 版本, 行号）确定性派生 |
| `lang` | `en` / `zh`，保留源语言 |
| `state` | 待判断的情境文本 |
| `questions[]` | 非空；每项 `{key, kind, prompt, options?, scale?}` |
| `targets` | `{<问题 key>: {answer, probs?}}`；本数据集 **100% 有此字段** |
| `source` | 溯源信息 |
| `meta` | 转换器信息与质量标记 |

        item = json.loads(line)
        for q in item["questions"]:
            key, kind = q["key"], q["kind"]          # choice / noul / score
            labels = [o["key"] for o in q.get("options", [])]   # score 题看 q["scale"]
            target = item["targets"][key]            # {"answer": ..., "probs": {...}}
        # 注意：score 题的 probs 键是数字下标 "0".."max"，不是 scale.labels 的文字

### 5.4 训练前的三件事

1. **按真值形态过滤，并正视硬标签占比**（§4.4）：做分布类损失只用"真概率分布"的 5,905 道；
   只用硬标签时一律取 `answer`，别把单点分布当概率。硬标签占 76.24%，
   若训练目标以软分布为主，需要相应调小分布类损失权重或改用硬标签主目标。
2. **按需重加权**（§2.2）：阅读 + 数学占 71.32%，直接按原始比例训练会把七成监督信号
   给到这两维。若要更均衡，按能力维度重加权或下采样即可，代价可控。
3. **意识到薄弱项**（§2.6）：世界知识 1.74%、因果/不确定性 0.81%，且中文只覆盖两处。
   指望这份数据单独补上这几块会失望——它们是下一轮补源的第一优先（§2.5）。

## 6. 复算

本页除**内部保留集的条数**（6,704）及由此相加得到的总量（78,060）——两者见
[split-report.md](split-report.md)——外，
每个分布数字都由同一个脚本算出，输入只有仓库内公开的三个分区文件：

    uv run --no-project --offline python datasets/general/readme_stats.py

    # 分类是否合理？按能力维度与内容领域各抽样打印真实条目，人工过一遍
    uv run --no-project --offline python datasets/general/readme_stats.py --samples 3

    # 写进文件（UTF-8）
    uv run --no-project --offline python datasets/general/readme_stats.py --out stats.md

脚本见 [readme_stats.py](readme_stats.py)：只用标准库、不联网、不用随机数，同一份输入两次运行
结果完全一致（两次运行输出文件的 sha256 相同）。两套口径的判定规则、映射表
（65 个原生领域标签、13 个任务键、28 种文档类型、**新并入来源的 32 个 config**）都在脚本里逐条列出，
可逐条核对。§2.5 的"按语料代际拆分"也在脚本输出里（§1.3）。

本页数字对应 `data/splits/` 目录的**当前版本**；若分区被重新切分，数字会随之变化，
以重跑结果为准（[split-manifest.json](data/splits/split-manifest.json) 记录了当次切分的哈希与清单）。
