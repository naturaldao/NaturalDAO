# Kev PoL2 counterfactual pilot: run record

This directory contains the exact sampled train, validation, and first-stage test rows, the training summary, full-grid counterfactual metrics, and per-case predictions. The experiment is exploratory and uses synthetic labels generated by `pol2-embodied-contract-v0.2.json`.

The six trained LoRA adapters and heads are not stored in Git. Their SHA-256 hashes, base checkpoint, software versions, and device are recorded in `results.json` and `counterfactual_results.json`. Recreate them in a new output directory with the training script linked from the [report](../../../../../../Research/Embodied/02-实验设计与审计/PoL2内在理论验证路线与反事实实验.md).
