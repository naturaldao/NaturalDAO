# 归档：通用 FT 最终评测工具（2026-10-27）

> 这些文件是 2026-10-27 通用数据 FT 线最终评测用的 CPU 工具与单测，随该线一起归档（owner 2026-10-28：该线不是目标所需的专有微调）。

| 文件 | 原用途 |
