# 结果共享

在 `results/<任务ID>-<模型>-<短名>/` 放 [结果卡](CARD.template.md)、运行配置与可公开的预测文件。大文件用固定 revision 的外部链接。尚未实际运行时不要提交占位分数。

结果卡链接登记到模型卡和任务页，其他人即使不合并该分支也能比较。

只比较三件事：PoL 判定、通用能力保持、主流安全测试；同时给出延迟/资源/成本和原模型或安全模型对照。保留失败与不确定结论。不同数据版本、硬件与预算单独列，不混成总排名。

私有保留集只发布汇总；不提交逐例内容、答案、模型响应或能反推案例的日志。
