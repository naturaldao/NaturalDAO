# 实验设计：模拟、反事实与下一步的真实实验

## 1. 研究问题

- **RQ1（平等联结 · 权力）**：把 20/80 的代币分配改成平等分配，会改变谁的选择胜出吗？
- **RQ2（平等联结 · 发言）**：由 PAI 保证轮流发言，能否在有敌意发言时保住少数派的声音？
- **RQ3（扬爱抑恨）**：EAP 筛查带来的收益（压制敌意）和代价（误伤正常批评）分别有多大？
- **RQ4（机制组合）**：以上三者和投票规则（二次方 / 排序）如何相互作用？

## 2. 用真实数据能回答的部分：平等预算反事实

**数据**：Sharma et al. (2026) Table 1 的平均预算份额 `mean_r_i`（`r_i = choice_i / votes_given`），以及每个条件每个选项的代币总数。两者均为论文公布的数字，已由 [dao-governance-replication](https://github.com/shentonyan/dao-governance-replication) 从 OSF 数据复现（Table 1 的 72 个数中 70 个一致，另 2 个是论文的印刷错误）。

**方法**：若每人预算都为 B、分配比例不变，则排序（线性）投票下选项 i 的总票数是 `B × n × mean_r_i`，所以胜出者就是 `mean_r_i` 最大的选项。这对线性投票是**精确的**。二次方投票下 `√(B × r)` 的和不能从平均数得到，需要逐张选票（`pol2dao replay`）。

**结果**：见 README。第 1 轮排序 20/80 条件翻转（选项 2 → 选项 3），差距 0.021；第 2 轮不翻转。

**不能说明的**：
- 差距在抽样误差之内（n = 25，份额的标准差约 0.2）。
- 人们在知道自己预算的情况下做了分配；预算相同时他们可能分得不一样。
- 这不是因果效应：分到 400 代币的人可能本来就和别人偏好不同。

## 3. 模拟模型（`src/pol2dao/simulate.py`）

### 3.1 设定

| 参数 | 默认值 | 含义 |
|---|---|---|
| `n` | 25 | 每组人数（接近论文各条件的 18–27 人） |
| `minority_frac` | 0.2 | 少数派占比 |
| `majority_u` | (0.2, 0.55, 0.45, 0.3) | 多数派对四个选项的效用：温和偏好选项 2 |
| `minority_u` | (0.0, 0.0, 1.0, 0.2) | 少数派：强烈偏好选项 3 |
| `noise` | 0.1 | 个人效用 = 群体效用 + N(0, 0.1)，截断到 [0, 1] |
| `rounds` | 3 | 审议轮数；共 3n 条发言 |
| `hate_rate` | 0（baseline）/ 0.3（hostile） | 多数派发言中敌意发言的比例 |
| `criticism_rate` | 0.5 | 少数派发言中批评性发言的比例 |
| `intimidation` | 0.5 | 出现未被标记的敌意发言后，少数派在自由发言中的发言倾向下降比例 |
| `persuasion` | 0.3 | 审议后每人向「所听到的发言者效用的平均」移动的比例 |
| `temperature` | 0.15 | 真诚型分配：代币 ∝ softmax(u / T) |
| `power_holders` | random / majority | 20/80 条件下，400 代币给谁 |

按人头平等计算，选项 3 的总效用约 14，选项 2 约 11，所以**选项 3 是平等权重下的最优选项，同时也是少数派的首选**。因此在本设定中「少数派胜出率」与「命中最优率」相同。

### 3.2 行为

- **自由发言**：下一个发言者按 √预算 的比例抽取（权力买到发言机会）；出现未被标记的敌意发言后，少数派发言倾向乘以 (1 − intimidation)。
- **轮流发言**：每人每轮一次，发言顺序在每组开始时随机打乱（不按群体排序）。
- **发言内容**：从带标签的小语料库中抽取（`HOSTILE_BANK`, `CRITICAL_BANK`, `NEUTRAL_BANK`），由真正的 `LexiconJudge` 筛查。语料库中故意放了一句没有关键词的敌意发言（会漏检）和一句对事不对人的粗话批评（会误报），因此筛查器的错误会真实地传到结果里。
- **被标记的发言**没有说服权重，也不会产生恐吓效应。
- **投票**：
  - 真诚型：代币 ∝ softmax(u / T)。
  - 策略型：排序投票全押首选；二次方投票代币 ∝ (u − 平均)₊²（效用对票数线性、成本为票数平方时的最优解）。

### 3.3 条件

| 条件 | 规则 | 权力 | 主持 | 筛查 |
|---|---|---|---|---|
| quadratic-equal | 二次方 | 平等 | 自由 | 否 |
| quadratic-20/80 | 二次方 | 20/80 | 自由 | 否 |
| ranked-equal | 线性 | 平等 | 自由 | 否 |
| ranked-20/80 | 线性 | 20/80 | 自由 | 否 |
| **pol2** | 二次方 | 平等 | 轮流 | 是 |
| pol2-no-screening | 二次方 | 平等 | 轮流 | 否 |
| pol2-free-talk | 二次方 | 平等 | 自由 | 是 |

前四个是论文的实验条件（论文的审议是自由的，没有筛查）。后两个是**消融**：分别去掉 PoL2 的一个部分，用来判断效果来自哪里。

所有条件使用相同的随机种子序列（共同随机数），每格 1000 次重复。

### 3.4 指标

| 指标 | 定义 |
|---|---|
| `minority_win` | 胜出选项 = 少数派首选的比例 |
| `regret` | 用审议**前**的效用、按人头平等计算：(最优总效用 − 胜出选项总效用) / (最优 − 最差) |
| `influence_gini` | 每人有效票数的基尼系数 |
| `nakamoto` | 合计超过 50 % 有效票数所需的最少人数 |
| `minority_voice_share` | 少数派发言占全部发言的比例（公平基准 = 0.2） |
| `hostile_miss_rate` | 敌意发言中未被标记的比例 |
| `benign_flag_rate` | 非敌意发言中被误标的比例 |

### 3.5 结果摘要（`results/tables/simulation_summary.csv`）

1. **权力集中在多数派时，平等权力是最大的杠杆。** 策略型、无敌意：排序投票 0.40 → 0.14，二次方 0.66 → 0.21。权力随机分配时，20/80 更像抽签：结果方差增大，平均影响较小。
2. **二次方投票更能反映强烈偏好**（策略型、平等权力：0.66 vs 0.42）。真诚型下两者都接近 1，因为模型里的少数派本来就几乎全押首选。
3. **轮流发言是对抗敌意的主要来源。** hostile 场景：少数派发言份额 0.12 → 0.20；策略型胜出率 0.34–0.40 → 0.67–0.68。
4. **筛查的净效果取决于有没有敌意。** 有敌意：0.67–0.68 → 0.74–0.76（约 20 % 敌意漏检）。没有敌意：0.67–0.70 → 0.60–0.62，因为关键词基线的误报集中在少数派的一句批评上。

更多实验（参数敏感性、偏好强度、规模、判定器质量与偏见、女巫攻击、PAI 自主决策、发言动态）见 [results.md](results.md)。

### 3.6 这些结果不能说明什么

- 所有数字都依赖上面的参数。改变 `intimidation`、`persuasion`、偏好强度，结论的大小（甚至方向）都可能改变。
- 语料库只有 14 句，判定器是关键词基线；真实筛查器的错误模式会不同。
- 模型没有表示：学习、联盟、跨轮次策略、对筛查的规避、对质询期的使用。
- 「少数派胜出」在这里等于「平等权重最优」只是因为设定如此；在少数派偏好较弱的设定下，二者会分开。

## 4. 下一步：一个可以真实开展的实验 ★

在 Sharma et al. 的 2 × 2 设计上加一个因素，作为预注册草案：

- **因素 A**：投票规则（二次方 / 排序）
- **因素 B**：权力（平等 / 20/80）
- **因素 C（新增）**：PoL2 审议（自由讨论 / PAI 轮流发言 + EAP 修复提示 + 质询期）

**主要结局**：少数派（按事前问卷的偏好强度定义）首选胜出与否；发言份额基尼系数；参与者对程序公平的评分（沿用论文的 Q1/Q2 量表以便比较）。

**次要结局**：被标记发言的人类复核结果（筛查的精确率与召回率）；质询数量与满意度；被标记者后续的发言量（检验「发言权不变」是否在心理上成立）。

**伦理**：筛查只产生修复提示，不删除内容、不限制发言；所有标记都经人类复核；参与者可查看关于自己的全部链上记录。

**样本量**：论文每格约 20–27 人、效应较小（第 1 轮 Pillai P = 0.023，第 2 轮不显著）。三因素设计至少需要每格 40 人以上，需要按预期效应做功效分析后再定。
