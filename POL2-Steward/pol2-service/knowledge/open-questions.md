# POL2 边界裁决记录

状态：2026-10-21 已由用户确认的适用边界。以下内容是工程解释与产品适用范围，不替代理论原文；如与理论维护方后续正式解释冲突，应记录冲突并升级。

| 编号 | 原问题 | 已确认处理 |
| --- | --- | --- |
| OQ-001 | 外部 Agent/SaaS 是否自动受生产公共化之约约束？ | 不自动。使用治理服务承担核心 EAP、诚实、不仇恨、生命尊严和基本权利约束；私有代码、客户数据和第三方资料不会因使用服务而自动公共化。进入 NaturalDAO 公共生产或使用公共资源时，按明确章程承担对应义务。 |
| OQ-002 | 完全透明与个人隐私、第三方资料、凭证如何划界？ | 默认公开规则版本、判定摘要、依据、条件、模型/服务版本和结果哈希；完整记录向授权审计者开放。个人资料、第三方隐私、凭证和内部隐含思维链按最小必要原则脱敏。 |
| OQ-003 | 资源有限时公共福利如何限制？ | 生命和基本健康保障设不可剥夺底线；资源稀缺采用公开、身份中性、可申诉的排队/分级标准，不因付费能力、身份、地域或贡献直接剥夺基本福利。 |
| OQ-004 | 文艺中的冲突和仇恨如何分级？ | 私人草稿不强制分级；公开发布、互动发行或可能影响现实行为时，标明受众、内容类型、强度提示和虚构性质。现实可操作伤害、未成年人性化和煽动仇恨另设硬门禁。 |
| OQ-005 | 安全防卫、警示和必要强制的边界是什么？ | 只在明确、可信、紧迫风险下允许警示或阻断；选择最小伤害手段，保留证据并复核。不得以安全为名实施先发攻击、报复或日常羞辱。 |
| OQ-006 | 哪些子协议对外部服务形成硬约束？ | 核心 EAP、诚实、不仇恨、生命尊严和基本权利为必要约束；生产公共化和公共福利协议在明确采用 POL2、使用公共资源或进入公共生产时形成硬约束。 |
| OQ-007 | 公理、核心协议和子协议冲突时如何排序？ | 四公理保持最高指导但按情境解释；不预设脱离语境的机械优先级。不可同时满足时记录冲突、风险和替代方案，优先减轻严重伤害并升级理论维护方。 |
| OQ-008 | 情绪语境理解与情感状态检测的工程界线是什么？ | 只处理用户明确提供的文本、当前交互和任务必需的情绪语义；允许经授权的任务必要文本分析，不做生物特征、心理诊断、人格画像或长期情绪档案。 |
| OQ-009 | 对外最低可审计披露包含什么？ | 决定、规则 ID 与版本、数据源、关键判断步骤、适用条款、条件、不确定性、模型标识和结果哈希。完整输入与审计证据只向授权角色开放。 |
| OQ-010 | 本服务是否属于 NaturalDAO 内部生产体系？ | 不属于。本服务是外部 Agent 治理服务；引用生产/福利协议作为公共目标与适用条款，但不声称已经实现公链、公共所有权和完整 NaturalDAO 自治。 |

## 执行约束

已批准的决定已写入规则映射的 `applicability`、`conditions_and_exceptions` 或 `decision_refs`。规则版本变更必须重新运行知识校验、包校验和行为回归；不能由模型自行改写本文件。
