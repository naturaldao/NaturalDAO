## 主要结论（摘要）

- **真实性（高置信）**：权重、参数账本、记忆参数与状态大小与论文逐位一致（Nano 35,111,542,048 / Flash 287,943,175,511；记忆状态 10,485,760 / 335,544,320 元素，FP32 下 40 MiB / 1280 MiB）。SGLang、HF modeling、社区 llama.cpp 三套实现与公式一致（独立重实现误差 3e-7）。**MoS 未交付**（权重、代码、配置都没有）。
- **诚信审查（中高置信）**：未发现伪造数据或伪造实验结构的证据；但存在训练/评测不可复现、参数记忆基线规模不对等（7 个中 6 个为 4–8B 且截断历史）、唯一同骨干基线 Temp-LoRA 反超却未在 Fig.1 呈现、SWE-bench Verified 100 题子集调参、若干内部数字矛盾（如附录 E.2、46.80 vs 46.98）。
- **含金量**：真实但被高估。核心是「冻结骨干 + 每会话持久线性注意力状态 + 轮末 GDN-2 写入」的高质量工程整合与 35B/288B 规模蒸馏，科学增量有限。
- **容量上限**：高熵事实多选题（4 选 1，随机 25%）N=10 时 52.5%，N≥20 后接近随机水平（23–30%）→ **N50≈10 条**；10M 状态元素不等于可存 10M 条事实。
- **同权重对照**（N=10，2 seeds）：原生记忆 40% / 无记忆 floor 15% / full-context 100% → **机制恢复率 ≈29%**（用汇总记忆 48.3% 则 ≈39%）。
- **干扰与遗忘**：20 条事实，无干扰 45% → 10 段无关文本约 20% → 30 段约 15%。
- **持久化**：写入 3/3、erase 2/3、restore 3/3；快照 41,943,056 B ≈ 40 MiB（与论文一致）。
- **应用场景**：C1 程序性经验 3/3（无记忆 0/3，full-context 3/3）；C2 复合偏好 2/3（部分生效）。
- **优化**：原文可得时 RAG top-1 100% 高于 native 30%，混合 100%；写入分批无影响、重复写入中性；状态精度 **FP16 误差 0.33% / BF16 2.74%**；FP16 端到端补丁工作状态 80→40 MiB/会话、召回不退化、延迟持平（服务端持久存储与快照仍 F32）。
- **scaling（负结果）**：mini 模型 v1–v4 未得到干净幂律；mini 的 N50 量级约 10²，明显高于真实模型的 N50≈10，提示真实模型瓶颈在训练目标与读出保真度，而非状态尺寸。

## 结论边界与局限

**核心边界：** 全部真实模型数字来自 CPU Q4 社区 GGUF + 社区补丁，非官方 BF16/GPU；官方 11 项 benchmark 无法在 CPU 复测，**不能与论文表格直接比较**。

**未复现 / 未验证清单（阅读时请按此打折）**

- 训练侧（34B tokens、两阶段蒸馏、MoS 的 E>1 版本）完全不可复现：上游仓库只有 inference，没有训练代码、数据、评测脚本与测试；
- MoS（E>1 容量扩展）未交付/未验证：发布模型 E=1，权重、代码与配置中都没有 router/address/expert 张量；
- 官方 BF16/GPU 推理未跑（Nano 约需 2×GPU / 70GB 权重，本机仅 T10 16GB）；
- 官方 11 项 benchmark 未复跑；Agentic coding / SWE-bench 未复现；论文 66× 等长历史与性能数字未实测；
- 训练数据泄漏无法验证；安全部分为静态审计（20 项发现：高 2 / 中 9 / 低 9），**不是渗透测试**，且部分结论依赖 SGLang 0.5.16 源码、未在本机验证；
- mini scaling 未得到干净幂律，**不外推**；FP16 端到端只减半工作状态，服务端持久存储与快照仍 F32（每会话存储未真正减半）；
- Q4 量化误差未单独测量；没有同规模基线，也没有官方「无记忆地板」；
- 自建多选题协议与合成场景，与真实使用分布存在差距；
- 页面含两套遗忘测量协议（固定段数笔记 vs 连续写入曲线），计量单位与阈值口径不同（页面分别写作约 400 token 与每批约 275 token），不可直接互比，请按对应小节阅读；
- 许可三方不一致：代码 PolyForm NonCommercial、论文 CC BY-NC-SA、权重 Apache-2.0（Nano）/ MIT（Flash），商用需上游澄清（本页为工程解读，不构成法律意见）。

**第三方安全审计摘要（静态审计，非渗透测试）：** 共 20 项发现（高 2 / 中 9 / 低 9）。高危 2 项：① 控制面 `/memt/control` 未鉴权（SGLang `--api-key` 是否覆盖待验证）；② Flash 客户端默认执行 checkpoint 内的 `encoding_dsv4.py`。其余为配置、资源与日志类风险；推理侧未见 eval/exec/pickle 等动态执行。详细证据见讲解页「安全与许可」章；我们将在后续跟进中联系上游核实。

## 与 NaturalDAO 记忆研究线的关系

- 与 [Memory Tax 论文](../Memory-Tax-Dissecting-the-Net-Value-of-Agent-Memory-arXiv-2610.34073v1.pdf) 互补：Memory Tax 提供「记忆净价值」的评估语言（memory benefit / tax / faithfulness / accessibility / robustness），本复现提供机制侧的独立测量与成本数据（容量 N50≈10、干扰衰减、FP16 减半）。
- 与 PoL2 存储方案中「训练原料、代理记忆与推理缓存分开管理」相呼应：固定大小状态不等于可检索存储；原文可得时，RAG 仍是更可靠的证据路径。
- 对 PoL Gate 的含义：记忆层的成本与保真度必须单列账本，不能用状态大小替代容量承诺。
