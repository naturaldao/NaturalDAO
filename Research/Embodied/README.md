# 具身智能与治理

[返回研究总入口](../README.md)

本方向研究：如何把 PoL2 规范转成任务级授权与行动约束，以及机器人在拒绝、授权撤回和执行故障后如何停止或恢复。

材料分成两条实验主线：**策略与决策**研究提示或训练是否改变动作选择；**门控、撤权与恢复**研究执行约束能否落实，以及中断后会留下什么物理状态。两条主线的证据不能相互替代。

## 结论边界

现有材料提供了类型化决策、确定性动作门和 MuJoCo Panda 仿真闭环的探索性证据。授权撤回系列进一步暴露出“阻断后续动作”和“恢复到有支撑的物理状态”之间的差别。

这些结果尚不能证明 PoL2 对通用机器人推理有总体净收益，也不能直接推出真实机器人安全性。先读[方法审计](02-实验设计与审计/PoL2-具身实验规范性与方法审计.md)可以了解证据边界；各轮的样本、条件和失败情况以原报告为准。
