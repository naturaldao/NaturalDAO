# 存储与数据基础设施

[返回研究总入口](../README.md)

## 推荐阅读路线

1. 快速了解领域：先读[AI 存储综述易读版](01-综述与选型/AI存储技术综述-易读版.md)。

3. 核查依据：回到[原综述](01-综述与选型/1.%20面向人工智能的存储技术：2025—2026%20年%20arXiv%20研究综述.md)、[研究笔记](04-调研笔记/)和原论文；容量计算见[复算与支撑](03-复算与支撑/README.md)。
